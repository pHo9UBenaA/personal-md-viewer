# Markdown Viewer

このリポジトリの `content/` にコピーした Markdown を、ファイルツリーとタブで読むためのツール。起動すると閲覧ウィンドウが開き、文書の閲覧や選択した文章へのマーカー追加ができる。マーカーはコピーにだけ保存し、元ファイルは変更しない。

自分の PC 内だけで利用し、サーバーはループバックアドレスだけで待ち受ける。外部には公開しない。コピー元など `content/` 外のファイルは開けず、ブラウザーのファイル選択やドラッグ＆ドロップによる取り込みにも対応しない。
