# Markdown Viewer

ローカルの Markdown を、ファイルツリーとタブで読むためのツールです。本文の編集機能は持たず、選択した文章へのマーカーだけを元の Markdown に保存できます。ビルドは不要です。

ローカルの本人利用向けです。サーバーとリバースプロキシはローカル限定で使ってください。外部公開は対象外です。

## 起動

初回、または依存関係の更新後は[必要環境と依存関係の準備](docs/development.md#準備)を済ませてください。リポジトリ直下で起動します。

```sh
pnpm start
```

表示された `http://127.0.0.1:3000` をブラウザーで開いてください。ブラウザーの自動起動はありません。終了はターミナルで Ctrl+C です。サーバーは `127.0.0.1` だけで待ち受けます。サーバーを再起動した後は、ブラウザーも再読み込みしてください。

起動時のファイル指定、サブフォルダーの探索、ポート変更は[利用ガイドの起動オプション](docs/usage.md#起動オプション)を参照してください。

## ファイルを開く

パス入力、ファイル・フォルダーの選択、ドラッグ＆ドロップに対応します。**元ファイルにマーカーを保存する場合は、パスで開いてください。** 詳しくは[ファイルの開き方](docs/usage.md#ファイルを開く)と[開き方による違い](docs/usage.md#開き方による違い)を参照してください。
