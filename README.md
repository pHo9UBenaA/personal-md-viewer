# Markdown Viewer

ローカルの Markdown を、ファイルツリーとタブで読むためのツールです。本文の編集機能は持たず、選択した文章へのマーカーだけを元の Markdown に保存できます。ビルドは不要です。

ローカルの本人利用向けです。サーバーとリバースプロキシはローカル限定で使ってください。外部公開は対象外です。

## 起動

Node.js 24 以上と pnpm 10.33.2 が必要です。リポジトリ直下で次を実行します。通常の閲覧に Caddy は不要です。

```sh
# 初回、または依存関係の更新後
pnpm install --frozen-lockfile
pnpm start
```

表示された `http://127.0.0.1:3000` をブラウザーで開いてください。ブラウザーの自動起動はありません。終了はターミナルで Ctrl+C です。サーバーは `127.0.0.1` だけで待ち受けます。

```sh
# 起動時にファイルやフォルダーを登録する（複数指定可）
pnpm start "/Users/you/Documents/one.md" "/Users/you/Documents/two.md"
pnpm start "/Users/you/Documents/notes"

# サブフォルダーも対象にする
pnpm start --recursive "/Users/you/Documents/notes"

# 3000 番ポートが使用中なら空きポートを使う
PORT=0 pnpm start
```

起動引数のフォルダーは、既定では直下だけを探します。配下を再帰的に探すには `--recursive` が必要です。登録したファイルはツリーに並び、最初の 1 件だけがタブで開きます。

開発用の自動再起動や Caddy を使う構成は、[開発ガイド](docs/development.md)を参照してください。

## ファイルを開く

- パス入力、または「開く・検索」からファイル・フォルダーのパスを指定できます。絶対パス、`~/...`、サーバーを起動したディレクトリからの相対パスに対応します。
- 「追加」からファイル・フォルダーを選択するか、画面にドロップして取り込めます。フォルダーのドロップは対応ブラウザーで利用できます。
- フォルダー内の `.md` / `.markdown` をツリーに登録し、最初の 1 件だけをタブで開きます。別のファイルはツリーから選んでください。
- 画面の「サブフォルダーも含める」は初期状態で有効です。パスからフォルダーを開くときに適用され、起動引数やブラウザーのフォルダー選択には影響しません。

### 開き方による違い

元ファイルにマーカーを保存したい場合は、パスで開いてください。

| できること・条件 | パスで開く（起動引数を含む） | ブラウザーで選択・ドロップする |
| --- | --- | --- |
| マーカーの保存・色変更・削除 | 元ファイルに保存できる | 保存できない。パスで開き直す |
| ディスク上の更新を反映 | 本文上部の「再読み込み」を押す | 更新後に再度選択・ドロップする |
| ブラウザーの再読み込み後 | 開いていたタブをディスクから復元する | 再度取り込む必要がある |
| 相対 Markdown リンク | 許可されたフォルダー内のファイルを開く | 同じ取り込みで登録したファイルを開く |
| 相対画像 | 許可されたフォルダー内から読む | 画像を含むフォルダーを取り込む |
| 取り込みの合計サイズ | 固定上限なし。個別ファイルの上限は適用 | Markdown 以外も含め、1 回の取り込みで合計 50 MiB まで |

パスで開いた同じ実ファイルはアプリ内で重複しません。ファイルを単独で開いた場合、相対リンク・画像の許可範囲はその親フォルダーです。フォルダーから開いた場合は選択したフォルダー以下です。範囲外の Markdown はパス入力で明示的に開いてください。

ブラウザーで取り込んだ相対 Markdown リンクの移動先は、同じ選択・ドロップで登録したファイルです。リンク先を事前にタブで開く必要はありません。

## 読む・操作する

| 操作 | 動作 |
| --- | --- |
| 「開く・検索」、⌘⇧P / Ctrl+Shift+P | パスを入力して開く、または取り込み済みのファイル名を検索。↑↓ と Enter でも選べる |
| 「全画面表示」、⌘⇧F / Ctrl+Shift+F | 閲覧中のタブを画面全体に表示。通常表示へは同じ操作、または Esc で戻る |
| ファイルツリー上で ⌘← | 展開されているフォルダーをすべて閉じる |
| タブの ← → / Home / End | 選択タブを切り替える。Delete で選択タブを閉じる |
| 「すべて閉じる」 | すべてのアプリ内タブを閉じる。ツリーの一覧は残る |
| ブラウザーの戻る・進む | タブの選択と開閉を履歴から復元する |
| 目次・見出しリンク | 本文の見出しへ移動する |
| Markdown 内の相対リンク | リンク先の Markdown をアプリ内タブで開く |
| 本文上部の「再読み込み」 | パスで開いたファイルをディスクから読み直す |
| 「ソース」 | Markdown 原文とプレビューを切り替える |
| 「別タブで開く」 | パスで開いたファイルを別のブラウザータブで読む。同じサーバー起動中のみ有効 |
| 「ライトへ」/「ダークへ」 | 画面と本文のテーマを切り替える。初回は OS 設定、以後は選択したテーマを使用 |
| サイドバーの境界をドラッグ | ファイルツリーと本文の幅を調整する |

### マーカーを保存する

パスで開いたファイルのプレビューで文章を選択し、近くに表示されるポップアップから緑・黄色・オレンジ・ピンク・青を選びます。元の Markdown に `<mark data-mdv-color="yellow">...</mark>` のようなタグを保存します。この形式のマーカーは、生 HTML を許可していない場合も描画します。

既存のマーカーを選択するかクリックすると、現在色に黒丸を表示します。別の色で変更し、× ボタンで外せます。**マーカーの一部だけを選択した場合も、色変更・削除はそのマーカー全体に適用します。** 再描画後も全画面表示と読んでいた位置を維持します。

以下の選択には対応しません。ポップアップが表示されない場合は、通常本文だけに選択範囲を狭めてください。

- コードブロック・インラインコードを含む範囲。
- 文字参照（`&amp;` など）やエスケープを含み、表示文字列と原文を対応付けられない範囲。
- 複数の既存マーカーをまたぐ範囲、またはマーカーの内側と外側にまたがる範囲。

保存時にファイルが別のアプリなどで更新されていた場合は、上書きせずエラーにします。本文上部の「再読み込み」を押して、選択し直してください。Markdown の構造を保てない場合も保存を中止します。その場合は選択範囲を狭めてください。

### ブラウザーの再読み込みと保存される設定

- パスで開いていたタブのパスと参照元フォルダーをセッション履歴に保存します。ブラウザーの再読み込み時は、本文をディスクから読み直します。履歴を消去した場合は復元できません。
- 画面からパスを指定して登録したフォルダーは、ブラウザーの再読み込み時に再探索しません。ツリーに登録しただけでタブを開いていなかったファイルを再表示するには、フォルダーを開き直してください。
- 起動引数で登録した一覧は、ブラウザーの再読み込み後もツリーに追加します。新しい履歴では、その一覧の最初のファイルを開きます。
- ブラウザーで選択・ドロップしたファイルは選択時点の内容です。ブラウザーの再読み込み後は再度取り込んでください。
- テーマとサイドバー幅を localStorage に保存します。テーマは同じオリジンの別タブにも反映します。保存が禁止されていても、そのページ内での切り替えは利用できます。

## 対応範囲と制限

- 見出し、リスト、表、取り消し線、引用、コード、リンクに対応します。GFM 完全互換ではなく、タスクリスト・脚注の専用拡張はありません。
- Mermaid はコード表示です。数式、構文色分けには対応しません。
- Markdown は 1 ファイル 1 MiB までです。
- Markdown 内の画像は、相対パスの PNG / JPEG / GIF / WebP / AVIF に対応します。1 ファイル 5 MiB、画像の記述は 1 ページ 100 件までです。外部 URL・絶対パスの画像は読み込まず、HTML・SVG は画像として配信しません。
- パスからの再帰探索とフォルダーのドロップは、深さ 32 までです。ブラウザーのフォルダー選択では、このアプリによる深さの検査はありません。
- パスからの探索では `.git` / `node_modules` / `.DS_Store` とシンボリックリンクをスキップします。フォルダーのドロップでは `.git` / `node_modules` をスキップします。ブラウザーのフォルダー選択には、これらを除く処理はありません。
- ファイル件数、タブ数、登録総数、探索項目数に固定上限はありません。本文は選択時に読み込みます。大量のファイルは探索時間やメモリー使用量を増やすため、対象を絞って開いてください。
- 開いているタブの本文キャッシュは、直近 10 タブを残すように削減します。ただし、閉じたタブの本文がファイル一覧側に残る場合があり、アプリ全体の本文保持数が 10 件以下になる保証ではありません。

## 生 HTML を表示する場合

通常は生 HTML を文字として表示し、`<!-- ... -->` のコメントだけを非表示にします。コード内のコメント表記はそのまま表示します。

信頼できるファイルで `<details>` / `<summary>` などを描画する場合は、次のように起動します。

```sh
pnpm start --allow-html "/Users/you/Documents/trusted.md"
```

`--allow-html` は、そのサーバーで開く**すべての Markdown**に適用します。後から取り込むファイルも信頼できるものに限ってください。スクリプト・フォーム・外部リソースの制限は維持しますが、HTML の全機能を安全化する仕組みではありません。

安全上の前提と保守時の注意は、[安全設計](docs/security.md)を参照してください。
