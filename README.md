# Markdown Viewer

専用の `content/` にコピーした Markdown を、ファイルツリーとタブで読むためのツールです。選択した文章のマーカーはコピーにだけ保存し、元ファイルは変更しません。ビルドは不要です。

ローカルの本人利用向けです。サーバーとリバースプロキシはローカル限定で使ってください。外部公開は対象外です。

## 起動

初回、または依存関係の更新後は[必要環境と依存関係の準備](docs/development.md#準備)を済ませてください。リポジトリ直下で起動します。

```sh
# Markdown と対応画像だけを content/notes/ にコピーする
pnpm copy-docs "/Users/you/Documents/notes"
pnpm start
```

表示された `http://127.0.0.1:3000` をブラウザーで開いてください。ブラウザーの自動起動はありません。終了はターミナルで Ctrl+C です。サーバーは `127.0.0.1` だけで待ち受けます。サーバーを再起動した後は、ブラウザーも再読み込みしてください。

引数なしでは `content/` 配下の Markdown を再帰的に一覧登録します。コピー方法と更新・削除は[コピーの管理](docs/usage.md#コピーの管理)、起動時の絞り込みやポート変更は[起動オプション](docs/usage.md#起動オプション)を参照してください。

## ファイルを開く

一覧から選ぶか、`content/` 内のパスを入力します。**コピー元など `content/` 外は開けません。** ブラウザーのファイル選択・ドロップによる取り込みもありません。詳しくは[ファイルの開き方](docs/usage.md#ファイルを開く)を参照してください。
