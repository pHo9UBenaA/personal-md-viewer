Viewer のショートカット

Viewer にフォーカスがある間、以下のキーを Viewer の操作に使う。 Preview・Raw の iframe 内でも使用できる。⌘ は macOS、Ctrl は Windows / Linux 向けの表記だ。 この案内ページではショートカットを変更しない。

キーViewer の動作ブラウザー標準動作との違い
⌘W / Ctrl+W選択したアプリ内タブを閉じる。未選択なら表示中のタブが対象。最後のタブを閉じても Viewer のウィンドウは残す。Chrome のタブ・ウィンドウを閉じない。Chrome アプリモードでの利用を想定する。
⌘R / Ctrl+R表示中の文書だけをコピーから読み直す。Viewer 全体は再読み込みしない。コピー元からの再コピーでもない。
⌘⇧F / Ctrl+Shift+F表示中の文書を全画面表示 / 解除する。Chrome の機能より Viewer の表示切り替えを優先する。Chrome 自体の全画面化ではなく、Viewer のツリー・タブなどを隠す。
⌘⇧P / Ctrl+Shift+P、⌘P / Ctrl+P「コマンドパレット」を開く。⌘P / Ctrl+P は印刷ではなく、コピー内のファイルを開く操作に使う。
⌘B / Ctrl+Bサイドバーの表示を切り替える。隠しても幅を保つ。入力欄・編集中の要素では上書きしない。/ や Ctrl+@ で検索欄へ移ると再表示する。
⌘⇧T / Ctrl+Shift+T最後に閉じた Viewer 内のタブを復元する。一括で閉じた操作はまとめて復元する。Chrome の閉じたタブは復元しない。画面内の直近 20 操作分を保持し、コピー内か再検証する。削除されたファイルやコピー外へ向くリンクは復元しない。
⌘⇧V / Ctrl+Shift+VRaw / Preview を切り替える。入力欄・編集中の要素では、書式なし貼り付けなどの標準操作を維持する。
⌘F / Ctrl+F表示中の本文内検索を開く。Preview のテキスト、または Raw の原文を検索する。Chrome のページ全体検索ではなく、本文だけを対象にする。大文字・小文字を区別せず、正規表現ではない文字列検索となる。
⌘G / Ctrl+G、⌘⇧G / Ctrl+Shift+G次 / 前の一致へ循環する。検索欄では Enter / Shift+Enter も使える。最後の本文検索の語を再利用し、現在の一致だけを強調する。検索語や強調は文書に保存しない。
Ctrl+Tab / Ctrl+Shift+Tab並び順で次 / 前のタブへ移動し、本文にフォーカスする。末尾と先頭を循環する。Chrome のタブではなく、Viewer 内のタブを移動する。複数選択を解除し、タブごとのスクロール位置を復元する。
Ctrl+@（US 配列: Ctrl+Shift+2）ツリーの絞り込み欄と表示中の本文のフォーカスを切り替える。タブがない場合は検索欄に留まる。検索欄へ移る際は全画面表示を解除する。日本語変換中には反応しない。
/ツリーの検索窓にフォーカスする。全画面表示中は通常表示に戻す。入力欄・編集中の要素・日本語変換中には反応しない。
Escメニューや検索を閉じる。本文ではマーカー選択、本文検索、全画面表示の順に解除する。ブラウザーの全画面状態は変更しない。

タブとツリー

  • Shift+クリックで、最初に選んだタブからクリック先までを範囲選択する。通常クリックで単一選択に戻る。背景色が一括操作の対象、アクセント線が表示中のタブを示す。
  • タブごとの Raw / Preview のスクロール位置は別々に保持する。閉じたタブ・履歴復元・画面全体の再読み込みでは位置を引き継がない。
  • タブにフォーカスがある間、← → / Home / End で切り替える。Shift と組み合わせると範囲選択する。Delete / Backspace で選択したタブを閉じる。
  • タブをドラッグして並び替える。右クリック、または Shift+F10 でパスのコピー・左右への移動・再読み込み・閉じる操作を選べる。メニューは ↑↓ と Enter で操作できる。
  • 右クリックしたタブが選択範囲内なら選択を保ち、範囲外ならそのタブだけを選択する。「選択したタブを閉じる」以外のメニュー操作は右クリックしたタブを基準にする。
  • ツリーは最初は閉じている。検索中は一致するファイルの親フォルダーを展開し、検索を消すと元の展開状態に戻る。ツリー上の ⌘← でフォルダーをすべて閉じる。

ツリー検索の「まとめて開く」

ツリーの絞り込み欄に空白以外の検索文字列があり、一致する登録済みファイルがあれば使える。 折りたたまれたフォルダー内も含め、結果全件をタブで開く。開いているタブは重複追加しない。 表示中の本文と位置を維持し、タブがない場合だけ最初の結果を表示する。本文は表示したときだけ読み込む。 新しく 50 件以上のタブを追加する場合は確認する。件数制限はないが、大量のタブは描画時間とメモリー使用量を増やす。 この欄と Ctrl+@ の移動先は同じで、⌘⇧P のコマンドパレットとは別の検索欄だ。

Chrome 標準の操作が必要な場合

通常の Chrome タブでは ⌘W / Ctrl+W をブラウザーが優先し、Viewer ごと閉じる場合がある。 Viewer 内の × ボタン、右クリックメニュー、またはタブにフォーカスして Delete / Backspace を使える。 アプリモードでも、アドレスバー・開発者ツールなど Viewer 外にフォーカスがある場合は Chrome の操作になる。 ダイアログ表示中は、Viewer が受け取った閉じる・復元・再読み込み・タブ移動・サイドバー・本文検索・表示切り替えを実行しない。 日本語変換中も割り込まない。Chrome 標準の印刷などが必要な場合は Chrome のメニューを使う。

サーバーを再起動した後など、Viewer 全体を読み込み直すには ⌘⇧R / Ctrl+Shift+R を使う。 Chrome のウィンドウを閉じる場合は OS の閉じるボタンを使う。ウィンドウを閉じても閲覧サーバーは止まらないため、起動したターミナルで Ctrl+C を押す。
