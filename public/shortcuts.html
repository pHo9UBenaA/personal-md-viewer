Viewer のショートカット

Viewer にフォーカスがある間、以下のキーを Viewer の操作に使う。 Preview・Raw の iframe 内でも使用できる。⌘ は macOS、Ctrl は Windows / Linux 向けの表記だ。 この案内ページではショートカットを変更しない。

キーViewer の動作ブラウザー標準動作との違い
⌘W / Ctrl+W選択したアプリ内タブを閉じる。未選択なら表示中のタブが対象。最後のタブを閉じても Viewer のウィンドウは残す。Chrome のタブ・ウィンドウを閉じない。Chrome アプリモードでの利用を想定する。
⌘R / Ctrl+R表示中の文書だけをコピーから読み直す。Viewer 全体は再読み込みしない。コピー元からの再コピーでもない。
⌘⇧F / Ctrl+Shift+F表示中の文書を全画面表示 / 解除する。Chrome の機能より Viewer の表示切り替えを優先する。Chrome 自体の全画面化ではなく、Viewer のツリー・タブなどを隠す。
⌘⇧P / Ctrl+Shift+P「コマンドパレット」を開く。ブラウザー標準動作より Viewer の検索を優先する。
/ツリーの検索窓にフォーカスする。全画面表示中は通常表示に戻す。入力欄・編集中の要素・日本語変換中には反応しない。
Escメニューや検索を閉じる。本文ではマーカーの選択を解除し、次の Esc で全画面表示を解除する。ブラウザーの全画面状態は変更しない。

タブとツリー

  • Shift+クリックで、最初に選んだタブからクリック先までを範囲選択する。通常クリックで単一選択に戻る。背景色が一括操作の対象、下線が表示中のタブを示す。
  • タブにフォーカスがある間、← → / Home / End で切り替える。Shift と組み合わせると範囲選択する。Delete / Backspace で選択したタブを閉じる。
  • タブをドラッグして並び替える。右クリック、または Shift+F10 でパスのコピー・左右への移動・再読み込み・閉じる操作を選べる。メニューは ↑↓ と Enter で操作できる。
  • 右クリックしたタブが選択範囲内なら選択を保ち、範囲外ならそのタブだけを選択する。「選択したタブを閉じる」以外のメニュー操作は右クリックしたタブを基準にする。
  • ツリーは最初は閉じている。検索中は一致するファイルの親フォルダーを展開し、検索を消すと元の展開状態に戻る。ツリー上の ⌘← でフォルダーをすべて閉じる。

Chrome 標準の操作が必要な場合

通常の Chrome タブでは ⌘W / Ctrl+W をブラウザーが優先し、Viewer ごと閉じる場合がある。 Viewer 内の × ボタン、右クリックメニュー、またはタブにフォーカスして Delete / Backspace を使える。 アプリモードでも、アドレスバー・開発者ツールなど Viewer 外にフォーカスがある場合は Chrome の操作になる。 「コマンドパレット」の表示中は、Viewer が受け取った閉じる・再読み込みのキーを実行しない。

サーバーを再起動した後など、Viewer 全体を読み込み直すには ⌘⇧R / Ctrl+Shift+R を使う。 Chrome のウィンドウを閉じる場合は OS の閉じるボタンを使う。ウィンドウを閉じても閲覧サーバーは止まらないため、起動したターミナルで Ctrl+C を押す。
