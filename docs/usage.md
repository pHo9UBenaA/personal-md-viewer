# 利用ガイド

`content/` にコピーした文書の起動・閲覧・マーカー保存を扱う。サーバーとリバースプロキシはローカルの本人利用に限定し、外部公開しない。コマンドはリポジトリ直下で実行する。

## 起動

初回、または依存関係の更新後は、[必要環境と依存関係の準備](development.md#準備)を済ませる。

```sh
# Markdown と対応画像だけを content/notes/ にコピーする
pnpm copy-docs "/Users/you/Documents/notes"
pnpm start
```

Markdown は 1 ファイル 1 MiB、対応画像は 1 ファイル 5 MiB、フォルダーは深さ 32 までコピーできる。既存の同名コピーは上書きしない。コピーと元ファイルは同期せず、マーカーはコピーだけに保存する。

表示された URL（既定は `http://127.0.0.1:3000`）をブラウザーで開く。ブラウザーの自動起動は行わない。サーバーは通常ユーザーで起動し、`127.0.0.1` だけで待ち受ける。終了はターミナルで Ctrl+C。サーバーを再起動した後は、ブラウザーも再読み込みする。

引数なしでは `content/` 配下の Markdown を再帰的に一覧登録する。空の `content/` でも起動できる。

## コピーの管理

アプリは、このリポジトリの `content/` にある文書だけを開く。コピー元にはフォルダーを指定する。

```sh
# content/notes/ にコピー（既定のコピー名は元フォルダー名）
pnpm copy-docs "/Users/you/Documents/notes"

# コピー名を明示する。日本語・空白も使用可能
pnpm copy-docs "/Users/you/Documents/notes" "読書メモ"

# 別のフォルダーも追加できる
pnpm copy-docs "/Users/you/Documents/work" "work-notes"
```

- `.md` / `.markdown` と PNG / JPEG / GIF / WebP / AVIF だけを、フォルダー構造を保ってコピーする。ファイルの内容は変更しない。
- Markdown は 1 ファイル 1 MiB、画像は 1 ファイル 5 MiB、フォルダーは深さ 32 まで。対応ファイルが上限を超える、Markdown がないなどの場合は失敗し、その実行で作ったコピーを削除する。元ファイルは変更しない。
- シンボリックリンクはファイル・フォルダーともスキップし、リンク先はコピーしない。通常ファイル以外もスキップする。`.git` / `node_modules` / `.DS_Store` は除外する。
- コピー名は単一のフォルダー名で、UTF-8 で 255 バイトまで。先頭の `.`、前後の空白、区切り文字、除外名（`node_modules` など）は使えない。
- **既存の同名コピーは上書きしない。** 元文書の更新を取り込むには、別のコピー名で実行する。コピーと元ファイルは同期せず、保存済みマーカーも新しいコピーへは引き継がない。
- マーカーはコピーだけに保存し、元ファイルには反映しない。必要なマーカーを退避せずにコピーを削除しない。
- 不要なコピーはサーバーを停止してから、`content/` 内の該当フォルダーを手動で削除する。`content/` 自体と `.gitkeep` は残す。
- コピー元と `content/` が互いに包含する配置は拒否する。コピー先ルートをシンボリックリンクにすることもできない。コピー用スクリプトを使い、`content/` にシンボリックリンクやハードリンクを手動で追加しない。
- `content/` のコピーは Git の対象外だが、暗号化はしない。機密文書の複製・バックアップ・削除は利用者が管理する。
- ファイル件数やコピーの合計サイズには固定上限がない。大量のファイルはディスク容量・探索時間・メモリー使用量を増やすため、対象を絞ってコピーする。

コピー中の不完全な一覧を避けるため、コピーはサーバー停止中に行うことを勧める。起動中に追加した場合は、画面から `content/` を開き直すか、サーバーを再起動してブラウザーを再読み込みする。

## 起動オプション

```sh
# 引数なし: content/ 全体を再帰的に一覧登録
pnpm start

# 起動時の表示範囲をコピー内に絞る（複数指定可）
pnpm start content/notes/one.md content/work-notes/two.md
pnpm start content/notes

# パス引数のフォルダーを再帰的に探す
pnpm start --recursive content/notes

# 3000 番ポートが使用中なら空きポートを使う
PORT=0 pnpm start
```

パス引数のフォルダーは、既定では直下だけを探す。配下を再帰的に探すには `--recursive` が必要。引数なしの場合は常に `content/` 全体を再帰的に探す。起動時の絞り込みはアクセス制限ではなく、コピー内の別のパスも画面から開ける。

## ファイルを開く

- ツリーから選ぶか、パス入力・「開く・検索」で `content/` 内のファイルやフォルダーを指定する。相対パスはサーバーを起動したディレクトリ基準。絶対パスや `~/...` も、コピー内を指す場合に限り使える。
- フォルダー内の Markdown をツリーに登録し、最初の 1 件だけをタブで開く。他のファイルはツリーから選ぶ。ツリーのフォルダーは初期状態では閉じている。検索中は一致するファイルの親を展開し、検索を消すと元の展開状態に戻る。
- 画面の「サブフォルダーも含める」は初期状態で有効。画面からフォルダーを開くときに適用し、起動引数には影響しない。
- **コピー元など `content/` 外のパスは、起動引数・画面入力・履歴復元のいずれでも拒否する。** 外部へのシンボリックリンクも開けない。
- ブラウザーのファイル・フォルダー選択とドラッグ＆ドロップによる取り込みには対応しない。ドラッグ操作は、開いているアプリ内タブの並び替えだけに使える。コピー方式への移行前のセッション履歴は引き継がないため、まずコピーしてから開き直す。

### 開き方による違い

どの開き方でもコピーだけが対象で、マーカーはコピーに保存する。

| 開き方 | Markdown 記法の相対リンク・画像の許可範囲 |
| --- | --- |
| 引数なしで起動 | `content/` 全体 |
| フォルダーのパスで開く | 指定したフォルダー以下 |
| 単独ファイルのパスで開く | ファイルの親フォルダー以下 |

いずれも `content/` の外には出られない。選択フォルダーの外でもコピー内であれば、パスを明示して開き直せる。

## 読む・操作する

| 操作 | 動作 |
| --- | --- |
| 「開く・検索」、⌘⇧P / Ctrl+Shift+P | コピー内のパスを開く、または登録済みのファイル名を検索。↑↓ と Enter でも選べる |
| 「全画面表示」、⌘⇧F / Ctrl+Shift+F | Viewer のツリー・タブなどを隠して本文を表示。Chrome 自体の全画面化ではない。同じ操作、または Esc で戻る |
| / | ツリーの検索窓にフォーカスする。全画面表示中は通常表示に戻る。入力欄・編集中の要素・日本語変換中には反応しない |
| ⌘W / Ctrl+W | 選択したアプリ内タブをまとめて閉じる。最後のタブを閉じても Viewer のウィンドウは残す |
| ファイルツリー上で ⌘← | 展開されているフォルダーをすべて閉じる |
| タブの ← → / Home / End | 表示するタブを切り替える。Shift と組み合わせると範囲選択。Delete / Backspace で選択したタブを閉じる |
| 「すべて閉じる」 | すべてのアプリ内タブを閉じる。ツリーの一覧は残る |
| ブラウザーの戻る・進む | 表示するタブ、開閉、並び順を履歴から復元する |
| 目次・見出しリンク | 本文の見出しへ移動する |
| Markdown 内の相対リンク | 許可範囲内の Markdown をアプリ内タブで開く |
| 本文上部の「再読み込み」、⌘R / Ctrl+R | 表示中の文書だけをコピーから読み直す。コピー元からの再コピーでも、Viewer 全体の再読み込みでもない |
| 「ソース」 | Markdown 原文とプレビューを切り替える |
| 「別タブで開く」 | 同じ文書を別のブラウザータブで読む。同じサーバー起動中のみ有効 |
| 「ライトへ」/「ダークへ」 | 画面と本文のテーマを切り替える。初回は OS 設定、以後は選択したテーマを使用 |
| サイドバーの境界をドラッグ | ファイルツリーと本文の幅を調整する |

ブラウザー標準のショートカットの一部を Viewer の操作に変更している。画面上部の「ショートカットの詳細」は別のブラウザータブで開く。⌘W / Ctrl+W は Chrome アプリモードでの利用を想定する。通常の Chrome タブではブラウザーが優先し、Viewer ごと閉じる場合があるため、× ボタン・右クリックメニュー・タブにフォーカスして Delete / Backspace も使える。Viewer 外にフォーカスがある場合は Chrome の操作になる。「開く・検索」の表示中は、Viewer が受け取った閉じる・再読み込みのキーを実行しない。

### タブをまとめて操作する

Shift+クリックで、最初に選んだタブからクリック先までを範囲選択する。通常クリックで単一選択に戻る。背景色が一括操作の対象、下線が表示中のタブを示す。閉じる操作でファイルは削除しない。

タブをドラッグして並び替えられる。右クリック、またはタブ上の Shift+F10 で、パスのコピー・再読み込み・左右への移動・閉じる操作を選べる。メニューは ↑↓ と Enter でも操作できる。パスのコピーにはブラウザーのクリップボード権限が必要な場合があり、失敗時は画面に通知する。相対パスは `content/` を除いたコピー内のパスとなる。

右クリックしたタブが選択範囲内なら選択を保ち、範囲外ならそのタブだけを選択する。「選択したタブを閉じる」以外は、右クリックしたタブを基準に操作する。再読み込みを選ぶと、そのタブを表示して本文を読み直す。

### マーカーを保存する

プレビューで文章を選択し、近くに表示されるポップアップから緑・黄色・オレンジ・ピンク・青を選ぶ。表の見出し・セル内の文章も選択できる。ファイルパスなど本文外の選択には表示しない。コピーした Markdown に `<mark data-mdv-color="yellow">...</mark>` のようなタグを保存する。この形式のマーカーは、生 HTML を許可していない場合も描画する。

既存のマーカーを選択するかクリックすると、現在色に黒丸を表示する。別の色で変更し、× ボタンで外せる。**マーカーの一部だけを選択した場合も、色変更・削除はそのマーカー全体に適用する。** 再描画後も全画面表示と読んでいた位置を維持する。

以下の選択には対応しない。ポップアップが表示されない場合は、通常本文だけに選択範囲を狭める。

- コードブロック・インラインコードを含む範囲。
- 文字参照（`&amp;` など）やエスケープを含み、表示文字列と原文を対応付けられない範囲。
- 複数の既存マーカーをまたぐ範囲、またはマーカーの内側と外側にまたがる範囲。

保存時にコピーが別のアプリなどで更新されていた場合は、上書きせずエラーにする。「再読み込み」を押して選択し直す。Markdown の構造を保てない場合も保存を中止するため、選択範囲を狭める。マーカー追加後も 1 ファイル 1 MiB の上限が適用される。

### ブラウザーの再読み込みと保存される設定

- Viewer 全体を読み込み直すには ⌘⇧R / Ctrl+Shift+R を使う。サーバー再起動後もこの操作が必要となる。
- 開いていたタブのパス・参照元フォルダー・並び順・表示中のタブをセッション履歴に保存する。再読み込み時は、コピー内かを再検証して本文を読み直す。複数選択は保存しない。履歴を消去した場合は復元できない。
- 画面から登録したフォルダーは、ブラウザーの再読み込み時に再探索しない。タブを開いていなかったファイルを再表示するには、フォルダーを開き直す。
- 起動時に登録した一覧は、ブラウザーの再読み込み後もツリーに追加する。新しい履歴では一覧の最初のファイルを開く。
- テーマとサイドバー幅を localStorage に保存する。テーマは同じオリジンの別タブにも反映する。保存が禁止されていても、そのページ内で切り替えられる。

## 対応範囲と制限

- 見出し、リスト、表、取り消し線、引用、コード、リンクに対応する。GFM 完全互換ではなく、タスクリスト・脚注の専用拡張はない。
- Mermaid はコード表示。数式、構文色分けには対応しない。
- Markdown は 1 ファイル 1 MiB まで。コピー時と閲覧・保存時に適用する。
- 対応画像は PNG / JPEG / GIF / WebP / AVIF、1 ファイル 5 MiB まで。コピー時と閲覧時に適用する。Markdown 記法の画像は相対パスだけを読み、1 ページ 100 件まで。外部 URL・絶対パスの画像は読み込まず、HTML・SVG は画像として配信しない。
- コピーと再帰探索は深さ 32 まで。`.git` / `node_modules` / `.DS_Store` とシンボリックリンクをスキップする。
- ファイル件数、登録総数、探索項目数、コピーの合計サイズには固定上限がない。本文は選択時に読み込む。大量のファイルはディスク容量・探索時間・メモリー使用量を増やすため、対象を絞ってコピーする。

## 生 HTML を表示する場合

通常は生 HTML を文字として表示し、`<!-- ... -->` のコメントだけを非表示にする。コード内のコメント表記はそのまま表示する。アプリが保存する固定形式のマーカー用タグは、生 HTML を許可しなくても描画する。

信頼できるファイルで `<details>` / `<summary>` などを描画する場合は、次のように起動する。

```sh
pnpm start --allow-html content/notes/trusted.md
```

`--allow-html` は、そのサーバーで開く**すべての Markdown**に適用する。コピー内でも信頼できるファイルだけを開く。スクリプト・フォーム・外部リソースの制限は維持するが、HTML の全機能を安全化する仕組みではない。

文書間の移動や画像表示には Markdown 記法を使う。生 HTML の相対リンクはアプリ内タブで開かず、`<img>` の相対パス画像も読み込まない。
