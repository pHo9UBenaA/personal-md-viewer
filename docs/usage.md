# 利用ガイド

コピーの管理、閲覧操作、対応範囲を説明します。通常の起動は [README の起動手順](../README.md#起動)、必要環境の準備は[開発ガイド](development.md#準備)を参照してください。

## コピーの管理

リポジトリ直下で実行します。アプリは、このリポジトリの `content/` にある文書だけを開きます。

```sh
# content/notes/ にコピー（既定のコピー名は元フォルダー名）
pnpm copy-docs "/Users/you/Documents/notes"

# コピー名を明示する。日本語・空白も使用可能
pnpm copy-docs "/Users/you/Documents/notes" "読書メモ"

# 別のフォルダーも追加できる
pnpm copy-docs "/Users/you/Documents/work" "work-notes"
pnpm start
```

- `.md` / `.markdown` と対応画像だけを、フォルダー構造を保ってコピーします。ファイルの内容は変更しません。
- シンボリックリンクはファイル・フォルダーともスキップし、リンク先はコピーしません。通常ファイル以外もスキップします。`.git` / `node_modules` / `.DS_Store` は除外します。
- 対応ファイルがサイズ上限を超える、フォルダーが深すぎる、Markdown がないなどの場合は失敗し、その実行で作ったコピーを削除します。元ファイルは変更しません。
- コピー名は単一のフォルダー名です。先頭の `.`、前後の空白、区切り文字、除外名（`node_modules` など）は使えません。
- **既存の同名コピーは上書きしません。** 保存済みマーカーを失わないためです。元文書の更新を取り込むには、別のコピー名で実行してください。
- コピーと元ファイルは同期しません。マーカーはコピーだけに保存され、元ファイルには反映されません。必要なマーカーを退避せずにコピーを削除しないでください。
- 不要なコピーはサーバーを停止してから、`content/` 内の該当フォルダーを手動で削除してください。`content/` 自体と `.gitkeep` は残してください。
- コピー元と `content/` が互いに包含する配置は拒否します。コピー先ルートをシンボリックリンクにすることもできません。
- `content/` のコピーは Git の対象外ですが、暗号化されるわけではありません。機密文書の複製・バックアップ・削除は利用者が管理してください。

コピー中の不完全な一覧を避けるため、コピーはサーバー停止中に行うことを勧めます。起動中に追加した場合は、画面から `content/` を開き直すか、サーバーを再起動してブラウザーを再読み込みしてください。

## 起動オプション

```sh
# 引数なし: content/ 全体を再帰的に一覧登録
pnpm start

# 起動時の表示範囲をコピー内に絞る（複数指定可）
pnpm start content/notes/one.md content/work-notes/two.md
pnpm start content/notes

# パス引数のフォルダーを再帰的に探す
pnpm start --recursive content/notes

# 3000 番ポートが使用中なら空きポートを使う
PORT=0 pnpm start
```

パス引数のフォルダーは、既定では直下だけを探します。配下を再帰的に探すには `--recursive` が必要です。引数なしの場合は常に `content/` 全体を再帰的に探します。空の `content/` でも起動できます。

## ファイルを開く

- ツリーから選ぶか、パス入力・「開く・検索」で `content/` 内のファイルやフォルダーを指定します。相対パスはサーバーを起動したディレクトリ基準です。絶対パスや `~/...` も、コピー内を指す場合に限り使えます。
- フォルダー内の Markdown をツリーに登録し、最初の 1 件だけをタブで開きます。他のファイルはツリーから選んでください。
- 画面の「サブフォルダーも含める」は初期状態で有効です。画面からフォルダーを開くときに適用され、起動引数には影響しません。
- **コピー元など `content/` 外のパスは、起動引数・画面入力・履歴復元のいずれでも拒否します。** 外部へのシンボリックリンクも開けません。
- ブラウザーのファイル・フォルダー選択とドラッグ＆ドロップによる取り込みは廃止しました。従来のセッション履歴は引き継ぎません。まずコピーしてから開き直してください。

### 開き方による違い

どの開き方でもコピーだけが対象で、マーカーはコピーに保存します。

| 開き方 | 相対 Markdown リンク・画像の許可範囲 |
| --- | --- |
| 引数なしで起動 | `content/` 全体 |
| フォルダーのパスで開く | 指定したフォルダー以下 |
| 単独ファイルのパスで開く | ファイルの親フォルダー以下 |

いずれも `content/` の外には出られません。選択フォルダーの外でもコピー内であれば、パスを明示して開き直せます。

## 読む・操作する

| 操作 | 動作 |
| --- | --- |
| 「開く・検索」、⌘⇧P / Ctrl+Shift+P | コピー内のパスを開く、または登録済みのファイル名を検索。↑↓ と Enter でも選べる |
| 「全画面表示」、⌘⇧F / Ctrl+Shift+F | 閲覧中のタブを画面全体に表示。通常表示へは同じ操作、または Esc で戻る |
| ファイルツリー上で ⌘← | 展開されているフォルダーをすべて閉じる |
| タブの ← → / Home / End | 選択タブを切り替える。Delete で選択タブを閉じる |
| 「すべて閉じる」 | すべてのアプリ内タブを閉じる。ツリーの一覧は残る |
| ブラウザーの戻る・進む | タブの選択と開閉を履歴から復元する |
| 目次・見出しリンク | 本文の見出しへ移動する |
| Markdown 内の相対リンク | 許可範囲内の Markdown をアプリ内タブで開く |
| 本文上部の「再読み込み」 | コピーから本文を読み直す。コピー元からの再コピーではない |
| 「ソース」 | Markdown 原文とプレビューを切り替える |
| 「別タブで開く」 | 同じ文書を別のブラウザータブで読む。同じサーバー起動中のみ有効 |
| 「ライトへ」/「ダークへ」 | 画面と本文のテーマを切り替える。初回は OS 設定、以後は選択したテーマを使用 |
| サイドバーの境界をドラッグ | ファイルツリーと本文の幅を調整する |

### マーカーを保存する

プレビューで文章を選択し、近くに表示されるポップアップから緑・黄色・オレンジ・ピンク・青を選びます。コピーした Markdown に `<mark data-mdv-color="yellow">...</mark>` のようなタグを保存します。この形式のマーカーは、生 HTML を許可していない場合も描画します。

既存のマーカーを選択するかクリックすると、現在色に黒丸を表示します。別の色で変更し、× ボタンで外せます。**マーカーの一部だけを選択した場合も、色変更・削除はそのマーカー全体に適用します。** 再描画後も全画面表示と読んでいた位置を維持します。

以下の選択には対応しません。ポップアップが表示されない場合は、通常本文だけに選択範囲を狭めてください。

- コードブロック・インラインコードを含む範囲。
- 文字参照（`&amp;` など）やエスケープを含み、表示文字列と原文を対応付けられない範囲。
- 複数の既存マーカーをまたぐ範囲、またはマーカーの内側と外側にまたがる範囲。

保存時にコピーが別のアプリなどで更新されていた場合は、上書きせずエラーにします。「再読み込み」を押して選択し直してください。Markdown の構造を保てない場合も保存を中止するため、選択範囲を狭めてください。

### ブラウザーの再読み込みと保存される設定

- 開いていたタブのパスと参照元フォルダーをセッション履歴に保存します。再読み込み時は、コピー内かを再検証して本文を読み直します。履歴を消去した場合は復元できません。
- 画面から登録したフォルダーは、ブラウザーの再読み込み時に再探索しません。タブを開いていなかったファイルを再表示するには、フォルダーを開き直してください。
- 起動時に登録した一覧は、ブラウザーの再読み込み後もツリーに追加します。新しい履歴では一覧の最初のファイルを開きます。
- テーマとサイドバー幅を localStorage に保存します。テーマは同じオリジンの別タブにも反映します。保存が禁止されていても、そのページ内で切り替えられます。

## 対応範囲と制限

- 見出し、リスト、表、取り消し線、引用、コード、リンクに対応します。GFM 完全互換ではなく、タスクリスト・脚注の専用拡張はありません。
- Mermaid はコード表示です。数式、構文色分けには対応しません。
- Markdown は 1 ファイル 1 MiB までです。コピー時と閲覧・保存時に適用します。
- 対応画像は PNG / JPEG / GIF / WebP / AVIF、1 ファイル 5 MiB までです。コピー時と閲覧時に適用します。相対パス画像だけを読み、1 ページ 100 件までです。外部 URL・絶対パスの画像は読み込まず、HTML・SVG は画像として配信しません。
- コピーと再帰探索は深さ 32 までです。`.git` / `node_modules` / `.DS_Store` とシンボリックリンクをスキップします。
- ファイル件数、登録総数、探索項目数、コピーの合計サイズには固定上限がありません。本文は選択時に読み込みます。大量のファイルはディスク容量・探索時間・メモリー使用量を増やすため、対象を絞ってコピーしてください。

## 生 HTML を表示する場合

通常は生 HTML を文字として表示し、`<!-- ... -->` のコメントだけを非表示にします。コード内のコメント表記はそのまま表示します。マーカー用タグの扱いは[マーカーを保存する](#マーカーを保存する)を参照してください。

信頼できるファイルで `<details>` / `<summary>` などを描画する場合は、次のように起動します。

```sh
pnpm start --allow-html content/notes/trusted.md
```

`--allow-html` は、そのサーバーで開く**すべての Markdown**に適用します。コピー内でも信頼できるファイルだけを開いてください。スクリプト・フォーム・外部リソースの制限は維持しますが、HTML の全機能を安全化する仕組みではありません。
